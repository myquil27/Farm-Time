Farm Time

Set the family code

This page is for whoever runs Farm Time. Choose the one code your family will use. The page turns it into database rules for you to paste into Firebase. Your code never leaves this device, and only the code you choose here will work.

At least 8 characters. Three or four words plus a number is easy to share and hard to guess. Capital letters and extra spaces don't matter.

Paste these rules into Firebase

  1. Open console.firebase.google.com and your Farm Time project.
  2. Go to Build → Firestore Database → Rules.
  3. Delete everything in the rules box, paste the rules below, and click Publish.
  4. Wait a minute, then open Farm Time and enter your code.
